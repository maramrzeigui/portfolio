## 🧱 Réalisation

- React + TypeScript avec Vite, animations Framer Motion, icônes Lucide.
- Tout le contenu est centralisé dans `src/data/cvData.ts` : modifier ce fichier suffit à mettre le portfolio à jour.
- Déployé sur Vercel.

```bash
npm install
npm run dev
```
