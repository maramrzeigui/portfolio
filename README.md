# Maram Rzeigui · Portfolio 3D

Portfolio interactif en forme de jeu : chaque île est un projet (problème réel → solution), avec avatar animé, mini-jeux et version CV classique.

- **Stack** : React 19, Vite, Three.js (React Three Fiber, Drei), Framer Motion
- **Lancer** : `npm install` puis `npm run dev`
- **Lien direct vers une île** : `/?niveau=5`
